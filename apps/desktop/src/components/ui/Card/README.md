# Card

`Card` groups related content in a standard reusable surface.

## Public API

- Standard div props, plus `padding` (`none`, `sm`, `md`, `lg`), `variant` (`card`, `panel`), `children`, and `className`.

## Accessibility

`Card` is presentational by default. Use semantic content inside it, or apply an appropriate landmark/label only when the content warrants one.

## Usage

```tsx
<Card padding="md">Related content</Card>
```
