# PersonalitySection

`PersonalitySection` displays JARVIS's personality/tone settings and the conversation-delete PIN (grouped here as a personal/privacy setting rather than an AI-provider one).

## Public API

- Takes no props.

## Accessibility

Composed using accessible `Select`, `Input`, and `Switch` components.

## Usage

```tsx
<PersonalitySection />
```

## Used By

`SettingsView`
