# AIProviderSection

`AIProviderSection` displays the settings related to configuring the underlying AI engine: provider, model, and API credentials. Personality/tone settings and the delete PIN live in `PersonalitySection` instead.

## Public API

- Takes no props.

## Accessibility

Composed using accessible `Select` and `Input` components.

## Usage

```tsx
<AIProviderSection />
```

## Used By

`SettingsView`
